# Проверка данных модели РУ

Веб-страница для проверки качества данных модели раздельного учёта: сквозной баланс по этапам, сверка со сводом отчётности, правила сопоставимости (R00–R13, S01–S05), поиск аномалий (Isolation Forest) и отчёт Excel.

**Открыть:** https://nurzhanabdualiev-star.github.io/dq-ru/

Файлы обрабатываются в браузере пользователя и никуда не загружаются. Нужен Chrome или Edge (2022 года и новее).
